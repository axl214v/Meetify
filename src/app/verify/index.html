    What this proves, and what it does not

    It proves that the files this site sends to your browser right now are byte for byte the files in the published list, and that the list belongs to a release in the public repository.

    It does not prove what our server does with your data. The server code is closed. It also checks only the files in the list: a file that is not in the list is not looked at.

    A page that checks itself can be altered together with what it checks. If this site were compromised, this page could say "all good" anyway. That is why the same check exists as a script you run on your own machine, with the files from the repository. Do it at least once.

    Check it without this page

    git clone https://github.com/axl214v/meetify
cd meetify
node tools/verify-live.js https://meetify.cc

    The manifest hash shown above should equal the one in the notes of the release on GitHub. Files in the admin area are behind a login and are not checked here; their hashes are in the list.

    If a file differs only in size by a few bytes, something between the server and you may be rewriting files (some proxies and content networks minify scripts or hide email addresses). Report it from the feedback page; do not assume the worst, and do not ignore it.
